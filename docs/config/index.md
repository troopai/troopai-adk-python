# Declarative Configuration

The `troopai.adk.config` subsystem lets you define agents and multi-agent
topologies as JSON or YAML documents instead of Python code. Documents are
validated against strict Pydantic models before assembly, giving you early
error detection, editor autocomplete via JSON Schema, and a clean separation
between configuration and behavior.
